1. First Time Setup:
   - Install Python 3.9+
   - Install Ollama (https://ollama.ai)
   - Run: setup.bat

2. Run Chatbot:
   - Double-click: START.bat
   - Open browser: http://localhost:7860

3. Stop Chatbot:
   - Close the command prompt window
   - Or press Ctrl+C
